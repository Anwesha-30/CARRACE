# 🚗 Car Racing Game (Java Swing)

A simple yet visually appealing **2D Car Racing Game** built using **Java Swing**.  
The player controls a car using keyboard arrow keys and avoids enemy cars to score points.

---

## 🎮 Game Preview
- Top-down racing view
- Smooth animation
- Keyboard-controlled car movement
- Real-time score tracking

---

## ✨ Features
- 🚗 Player car movement using arrow keys
- 🚙 Randomly generated enemy cars
- 💥 Collision detection
- 🧮 Score increases as enemies are avoided
- 🎨 Clean and minimal UI (road, lanes, cars)

---

## 🛠️ Technologies Used
- **Java**
- **Java Swing**
- **AWT Graphics**
- **OOP Concepts**
- **Event Handling**
